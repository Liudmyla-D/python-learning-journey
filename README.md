# 🐍 python-learning-journey

✨ **My Python learning path:** homework, mini projects, and hands-on practice *(Data Analyst track)*.

---

## ✅ What’s inside

📚 Домашні завдання у форматі **Jupyter Notebook (.ipynb)**, згруповані за модулями навчання.

У цьому репозиторії зібрані практичні роботи з Python, SQL, аналізу даних, візуалізації, статистики, машинного навчання та роботи з великими даними.

---

## 🧠 Topics covered

### 📦 Module 9 — Python basics
- 🧩 синтаксис, типи даних  
- 🔀 умови (`if / else`)  
- 🔁 цикли (`for`, `while`)  
- 📦 колекції (`list`, `dict`, `set`)  
- 🧠 функції  
- ⚠️ обробка помилок, модулі  

### 📊 Module 10 — Data analysis (Pandas, NumPy)
- 🧮 робота з масивами та таблицями  
- 🔍 очищення та трансформація даних  
- 📊 `groupby`, `apply`, `pivot`  

### 📈 Module 11 — Data visualization
- 📊 візуалізація з **Matplotlib** та **Seaborn**  
- ⚡ інтерактивні графіки з **Plotly**  
- 🧾 оформлення графіків для аналітичних висновків  

### 🔗 Module 12 — Data & integration
- 🗄 SQL + Python  
- 🔄 робота з транзакціями  
- 🌐 API та ETL-пайплайн  
- 🧩 інтеграція Python із базами даних  

### 🧪 Module 15 — Statistical hypothesis testing & A/B testing
- 📐 перевірка статистичних гіпотез  
- 🧮 Z-test, тести для малих вибірок та пропорцій  
- 📊 аналіз A/B-тестів  
- 🧠 інтерпретація p-value та статистичних результатів  

### 🤖 Module 16 — Machine learning basics for Data Analysts
- 🏠 прогнозування орендної плати за житло  
- 💳 прогнозування кредитного ризику  
- 🧹 підготовка даних для моделей  
- 📈 базове навчання та оцінка ML-моделей  

### 🧼 Module 17 — Analytical workflow optimization
- 🧹 принципи чистого коду  
- 🧠 покращення читабельності Python-коду  
- 🛠 оптимізація аналітичної роботи  
- 📌 підходи до структурування коду та notebook-файлів
